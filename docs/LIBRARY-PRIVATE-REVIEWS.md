# Private ratings and notes in My Library

Implemented 2026-10-22. Saved movies, series and anime have an optional private integer score from 1 to 10 and a plain-text note of up to 2,000 characters. Notes can be saved without a score and vice versa. The library shows a distinct red **YOUR RATING** section beneath each poster, with a clipped note preview. The modal displays the full note and lets the user edit or clear either field and save changes. A separate **My highest rated** sort places unrated entries last. History retains its previous display and sorting.

The two fields live directly on the existing `public.watchlist` row: `personal_rating` (nullable smallint) and `personal_note` (non-null text, default empty). This uses the existing owner-only RLS rather than adding a second table, joins or per-card requests. The library fetches them with its existing 18-entry page query. Mutations require both the signed-in user's ID and the saved row ID, update only the private fields, and require a returned row before reporting success. Database constraints independently enforce the range and note length. Notes render as escaped React text, never HTML. No service key or new permissions are introduced.

No TMDB/AniList rating, catalog score, title detail score, public review or `MediaTile.rating` value is changed. The private section is rendered only in the watchlist view of My Library. The personal data is not added to public catalog caches or history. The app's normal RLS protects it from other accounts, including direct REST callers.

Removing a saved title also removes its review, with no orphaned note records. A shared preflight checks for a review and asks for explicit confirmation before removing a reviewed title, whether initiated from My Library or from a detail page. Preflight errors block deletion. Confirmation errors remain visible inside the dialog. Clearing watch history does not touch private reviews.

The editor is a native modal dialog with focus containment, Escape/Cancel, focus restoration, a character counter, disabled in-flight controls and retryable errors. Radio inputs support keyboard rating selection. Content and backdrop animate in, the dialog animates out, rating choices have hover previews, and cards have subtle hover/focus treatment. Reduced-motion preferences are respected. Narrow screens use a five-column/two-row rating selector.

Schema reference: `docs/sql/library-private-reviews.sql` (already applied; do not rerun on the existing project). CLI initialization was unavailable, so no migration history entry was invented. Review the existing watchlist RLS policies before applying this script to another deployment.

Verification: seven new unit/integration-client tests cover validation, private-field-only updates, owner/row filters, failed/zero-row saves, reviewed-title removal preflight, confirmed deletion filters and blocked deletion on preflight failure. A rolled-back PostgreSQL fixture confirms owner save/read, database constraints and non-owner isolation without modifying any existing user content. Security advisors before/after have the same existing trigger-function/password-protection warnings; no new advisory was introduced by the review columns. Browser QA uses a dedicated temporary fixture that is removed afterward.
